# ALBA · Beyond the Water

![ALBA — Beyond the Water](alba%20-%20banner.webp)

Una jornada de pesca desde el muelle de Lago Sereno. Observa el agua, elige el cebo y trabaja la tensión del sedal para llevar la captura al cuaderno. **v0.5.0 · A World Alive · Pre-Alpha** incorpora viento en la vegetación, humedad de la orilla y paisaje sonoro ambiental. El paquete npm conserva el número 0.4.0.

[Pescar en GitHub Pages](https://isjustmontes.github.io/alba-beyond-the-water/) · [Cómo jugar](docs/user-guide/README.md)

## Ejecutar en local

Con Node.js y npm (CI usa Node 22), ejecuta `npm ci` y `npm run dev`. Abre la dirección que imprime Vite. Three.js dibuja el lago; JavaScript, HTML y CSS gestionan la simulación y la interfaz. Web Audio sintetiza el sonido.

Ejecuta `npm test` para la simulación y `npm run build` para compilar. Con el servidor activo y Chromium disponible, `npm run test:browser` recorre la experiencia de pesca.
