# Producto y alcance

ALBA recrea la observación y la toma de decisiones de una jornada de pesca en solitario. La cámara permanece en un muelle. La elección de cebo, el momento de clavar y la gestión de tensión enlazan las condiciones del lago con el resultado. La escala de progreso actual es el récord personal de cada especie.

La entrega Pre-Alpha abarca una localización procedural, cinco especies, tres cebos, diario local y controles de escritorio y táctiles. El diseño no define un final de campaña. Economía, multijugador, estaciones y nuevos lagos quedan fuera de la entrega auditada.

En la rama v0.6.0, [M07 · First Steps](../milestones/M07-first-steps/README.md) incorpora A validada (paseo por el muelle) y B implementada pendiente de validación del propietario (conexión a ribera, sendero y dos puestos nuevos). No está publicado y no habilita exploración libre del mapa, nuevas zonas temáticas ni progresión.

**Vocabulario.** Una picada abre la ventana para clavar. Clavar inicia el combate. La holgura mide el tiempo con tensión insuficiente. La afinidad pondera el interés del pez por un cebo. LOD designa el modelo simplificado a distancia.
