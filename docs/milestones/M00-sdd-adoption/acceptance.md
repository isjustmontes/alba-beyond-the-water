# Aceptación · Adopción SDD

Entrada: checkout fijado, inventario original disponible. Salida: cumplir los criterios de las tareas siguientes.

- Recuperar todas las secciones y referencias desde el registro — VERIFIED.
- Navegar desde el contrato hasta requisito, tarea, criterio y evidencia — VERIFIED.
- Ejecutar los comandos disponibles y registrar también fallos y límites — VERIFIED.

La implementación, el resultado de las pruebas y la publicación son decisiones distintas. El cierre formal por el propietario no consta en esta auditoría.
